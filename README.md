  Mockup de um sistema de estoque fictício para uma loja de eletrônicos, desenvolvido como parte de um trabalho de SQL.
### _Protótipo — os dados são fictícios e ainda não são salvos em um banco de dados._

#### Funcionalidades

- Cadastro e edição de produtos;
- Entrada e saída de estoque;
- Busca por produtos;
- Controle de estoque mínimo;
- Identificação de produtos com estoque baixo;
- Modo claro e escuro;
- Interface responsiva.

#### Tecnologias para o Front-end

- HTML
- CSS
- SQL (conceito do projeto)
